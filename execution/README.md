1. Dzień 1–5: CRM + profile social + pierwsza fala outreach (harmonogram, dni 1–5)
2. Tydzień 2: kontakt z gminami, publikacje wg kalendarza FB i siatki IG
3. Tydzień 3: porozumienia z gminami, sprzęt, webinar rodziców
4. Tydzień 4: trzy warsztaty pilotażowe + raport wpływu nr 1 → paliwo dla sprzedaży B2B
